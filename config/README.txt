  📁 Configuration Directory
═══════════════════════════════════════════════════════════════

This folder contains configuration templates and local-only sensitive files:

📄 config.py          - General settings
📄 password.example.txt - Template for local password.txt
📄 5sim_config.example.txt - Template for local 5sim_config.txt
📄 user_agents.txt    - User agents list

⚠️ Important: Copy the example files to password.txt and 5sim_config.txt locally. Real secrets are ignored by git and should never be committed.
